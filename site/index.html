prev

Fast, easy document and image preview. Any PDF, including forms, annotations and encryption. Markdown files, most image formats, including RAW and SVG. Review, annotate, sign and redact by yourself, or using your favorite AI model or agent tools.

Free and open source under AGPL 3 on Linux, Windows and macOS. In 38 languages, including right-to-left.

What prev does

PDFs, fast

Pages render in tiles as you scroll, with thumbnails, the table of contents, bookmarks, search that highlights every match, text selection, links, full screen, slideshow and printing.

Markup and forms

Highlight, underline, draw, add shapes, arrows, text boxes and notes, and fill in forms. All saved as standard PDF annotations.

Signing

Draw your signature with a mouse, pen or touchpad, type it in a handwriting font, or bring in a scan with the paper made transparent. Keep as many as you like in the Sign menu, and place one on a PDF or a photo with a click.

Page editing

Reorder, rotate, delete, crop and insert pages, drag them between documents or out as a PDF, and export pages as images or a smaller, encrypted or flattened PDF.

Redaction

Mark text or areas and apply: what was underneath is removed from the file for good, not just covered, and no earlier revision keeps it.

Photos

PNG, JPEG, WebP, AVIF, HEIC, TIFF, camera RAW and more. Crop, rotate, resize and adjust color with undo, mark up, print, and export to nine formats. Edits keep EXIF and color profiles.

SVG and Markdown

SVG drawings stay sharp at any zoom. Markdown shows with tables, task lists and highlighted code, reloads as you edit, prints on pages and exports as a picture.

An assistant beside the page

Ask about a document in a chat panel, and the assistant reads what it needs, points things out and marks up, edits or fills it in for you, with Undo. Use a local model that stays on your computer, or a cloud model from Anthropic, OpenAI or Google with your own key.

AI agents

Agents such as Claude Code control the prev you are using over MCP, in your own windows, only once you allow them, and asking before the steps you choose, such as printing.

prev in your language

The interface comes in 38 languages and follows your system, laid out right to left for Arabic, Hebrew, Persian and Urdu. Here is the same annual report in six of them.

At home on each system

The same app on Linux, Windows and macOS, with each system's own window, shortcuts and, on the Mac, the menu bar.

Code signing policy

Windows releases of prev, since 2.2.1, are signed by Scramble Tools LLC with Microsoft Azure Artifact Signing.

  • What is signed: only programs built from this project's own source code by its GitHub Actions release workflow: prev.exe and the prev installer. Open source components prev bundles unchanged, such as libheif, libde265 and aom, are not signed with this certificate.
  • Committers and reviewers: the members of the scrambletoolsllc GitHub organization, who review every outside contribution before it is merged.
  • Approvers: the owner of the scrambletoolsllc GitHub organization, who alone can publish a release, and with it a signing.
  • Signing runs only in the release workflow, which signs in to Azure without a stored secret. Everyone on the team signs in to GitHub and Azure with two-factor authentication.

Privacy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it. prev goes online only to fetch a picture you drop onto it as a web address, to open links you click, and, when you use the assistant with a model you added, to send that model your messages and what it asks to read from the file you are working on: to the provider you chose for a cloud model, or to the server you gave for a local model. API keys stay in your system's keychain. prev has no accounts and sends no telemetry. This website sets no cookies and loads nothing from other sites.
